# Journey photographs

Nine images drive the pinned scroll section. Drop them here as **`<name>.jpg`**
using the names below. A beat with no file falls back to a flat tint, so the
section keeps working while you are still buying imagery.

| File | Shot to look for |
| --- | --- |
| `forest.jpg` | Dense montane forest interior, shafts of morning light through canopy, mist, no people |
| `grove.jpg` | Coffee shrubs growing under tall shade trees, dappled light, forest floor visible |
| `hillside.jpg` | Terraced highland coffee farm at altitude, layered ridges receding into haze |
| `picking.jpg` | Hands picking ripe red coffee cherries, close crop, shallow depth of field |
| `drying.jpg` | Coffee drying on raised beds in rows, strong sun, workers turning the beans |
| `sorting.jpg` | Dry mill interior, hand sorting green beans on long tables |
| `sacks.jpg` | Stacked jute coffee sacks in a warehouse, stencilled markings, warm side light |
| `container.jpg` | Shipping container being loaded at a port, doors open, cargo visible |
| `ship.jpg` | Container ship leaving port at dusk, wide horizon, warm sky |

## Specs

- **Landscape**, minimum **2400 px** wide. They are shown full-bleed and cropped
  to cover, so keep the subject near the centre.
- Export as JPEG, quality ~78. Aim for **under 400 KB each** — nine of these load
  on one section, so the total matters more than any single file.
- A **dark scrim sits over the bottom half** for copy legibility. Images with a
  busy or bright lower third will fight it; prefer ones that fall away into
  shadow at the bottom.

## Consistency matters more than any individual image

These nine are seen in sequence, so they must look like one shoot. Pick a single
direction and hold it across all nine — warm and golden, or cool and misty, not
both. Mismatched white balance across the set is the fastest way to make a stock
sequence look like stock.

## Licensing

Buy a **commercial / extended licence** for each image — a standard editorial
licence does not cover marketing use. Keep the receipts and licence IDs
somewhere durable; a buyer's legal team occasionally asks.

Real photographs of your own farms and washing stations would be considerably
more persuasive than stock, and can be swapped in later using the same filenames
with no code change.
